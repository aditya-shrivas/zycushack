# Configuration reference: Dashboard routing

## Location
Admin > Spend Analytics > Settings > Dashboard > Routing

## Purpose
Controls the routing applied when a dashboard is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Legacy behaviour |
| 5 minutes | Legacy behaviour |
| 90 days | Recommended for most tenants |
| Global | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-6213 and E-6182.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
