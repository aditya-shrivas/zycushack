# How to: Award an event

## Before you start
Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Sourcing settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

## Steps
1. Sign in as a Sourcing administrator.
2. Go to Sourcing > Settings.
3. Select the option for: award an event.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
