# Configuration reference: Bid submission validation

## Location
Admin > Sourcing > Settings > Bid submission > Validation

## Purpose
Controls the validation applied when a bid submission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Requires L2 enablement |
| Global | Recommended for most tenants |
| On | Requires L2 enablement |
| 60 minutes | Use for high-volume tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-3185 and E-3398.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
