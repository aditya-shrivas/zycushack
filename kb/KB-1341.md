# How to: Configure risk questionnaires

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

## Steps
1. Sign in as a Supplier Management administrator.
2. Go to Supplier Management > Settings.
3. Select the option for: configure risk questionnaires.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
