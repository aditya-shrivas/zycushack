# Configuration reference: Requisition mapping

## Location
Admin > eProcurement > Settings > Requisition > Mapping

## Purpose
Controls the mapping applied when a requisition is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Requires L2 enablement |
| 60 minutes | Legacy behaviour |
| Strict | Recommended for most tenants |
| On | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-1172 and E-1198.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
