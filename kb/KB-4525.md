# Configuration reference: Supplier profile retention

## Location
Admin > Supplier Management > Settings > Supplier profile > Retention

## Purpose
Controls the retention applied when a supplier profile is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Recommended for most tenants |
| 5 minutes | Requires L2 enablement |
| Global | Recommended for most tenants |
| 90 days | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a supplier profile is processed in bulk or immediately after an administrator changes Supplier Management settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-5104 and E-5367.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
