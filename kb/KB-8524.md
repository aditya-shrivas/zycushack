# Configuration reference: Rfx event tolerance

## Location
Admin > Sourcing > Settings > Rfx event > Tolerance

## Purpose
Controls the tolerance applied when a RFx event is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Use for high-volume tenants |
| Global | Use for high-volume tenants |
| Strict | Legacy behaviour |
| 30 days | Recommended for most tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-3126 and E-3376.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
