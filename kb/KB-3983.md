# Configuration reference: Clause library attachment limit

## Location
Admin > Contracts > Settings > Clause library > Attachment limit

## Purpose
Controls the attachment limit applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Legacy behaviour |
| On | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |
| 30 days | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a clause library is processed in bulk or immediately after an administrator changes Contracts settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-2138 and E-2156.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
