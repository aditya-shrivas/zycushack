# Configuration reference: Supplier profile mapping

## Location
Admin > Supplier Management > Settings > Supplier profile > Mapping

## Purpose
Controls the mapping applied when a supplier profile is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Requires L2 enablement |
| Per business unit | Legacy behaviour |
| Off | Requires L2 enablement |
| 90 days | Legacy behaviour |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a supplier profile is processed in bulk or immediately after an administrator changes Supplier Management settings. An incorrect value here is a common contributor to E-5176 and E-5327.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
