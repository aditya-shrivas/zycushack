# Configuration reference: Budget check retention

## Location
Admin > eProcurement > Settings > Budget check > Retention

## Purpose
Controls the retention applied when a budget check is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Recommended for most tenants |
| Global | Use for high-volume tenants |
| Off | Recommended for most tenants |
| Lenient | Requires L2 enablement |

## Impact of changes
Customers typically report this when a budget check is processed in bulk or immediately after an administrator changes eProcurement settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-1198 and E-1325.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
