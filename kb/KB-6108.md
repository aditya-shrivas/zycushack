# Configuration reference: Spend cube refresh tolerance

## Location
Admin > Spend Analytics > Settings > Spend cube refresh > Tolerance

## Purpose
Controls the tolerance applied when a spend cube refresh is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Legacy behaviour |
| On | Requires L2 enablement |
| Per business unit | Use for high-volume tenants |
| Strict | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a spend cube refresh is processed in bulk or immediately after an administrator changes Spend Analytics settings. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-6169 and E-6258.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
