# FAQ: Can a RFx event be restored after deletion?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a RFx event is processed in bulk or immediately after an administrator changes Sourcing settings.
