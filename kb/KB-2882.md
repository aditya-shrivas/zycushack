# FAQ: Does the bid submission support multiple currencies?

## Answer
Retention follows the tenant's data retention policy, which is 7 years by default.

## Details
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a bid submission is processed in bulk or immediately after an administrator changes Sourcing settings.
