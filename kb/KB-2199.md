# Configuration reference: Api token timeout

## Location
Admin > Integrations > Settings > Api token > Timeout

## Purpose
Controls the timeout applied when a API token is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Legacy behaviour |
| Global | Use for high-volume tenants |
| Strict | Use for high-volume tenants |
| 5 minutes | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a API token is processed in bulk or immediately after an administrator changes Integrations settings. An incorrect value here is a common contributor to E-7141 and E-7204.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
