# Configuration reference: Budget check routing

## Location
Admin > eProcurement > Settings > Budget check > Routing

## Purpose
Controls the routing applied when a budget check is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Use for high-volume tenants |
| Global | Requires L2 enablement |
| 30 days | Use for high-volume tenants |
| 5 minutes | Requires L2 enablement |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-1101 and E-1172.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
