# FAQ: Why does the 3-way match show a different status for some users?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a 3-way match is processed in bulk or immediately after an administrator changes eInvoice settings.
