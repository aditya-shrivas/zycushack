# [DEPRECATED] E-1172: Catalog item fails to save

> This article is deprecated and kept for audit history only. It describes behaviour on release 24.x. See KB-7145 for the current procedure.

## Symptoms
Users see error **E-1172** when a catalog item fails to save.

## Cause (release 24.x)
Browser plug-in incompatibility.

## Resolution (release 24.x)
1. Ask the customer to clear the browser cache and retry.
2. If the error persists, reinstall the legacy browser plug-in.
3. Raise an L2 ticket if the error persists after 24 hours.
