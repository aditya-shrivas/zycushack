# Configuration reference: Renewal alert currency

## Location
Admin > Contracts > Settings > Renewal alert > Currency

## Purpose
Controls the currency applied when a renewal alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Recommended for most tenants |
| 60 minutes | Recommended for most tenants |
| Strict | Legacy behaviour |
| Global | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-2378 and E-2326.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
