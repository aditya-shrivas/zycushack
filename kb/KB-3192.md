# FAQ: Can we export budget check data on a schedule?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
Customers typically report this when a budget check is processed in bulk or immediately after an administrator changes eProcurement settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
