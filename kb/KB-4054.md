# Configuration reference: Bid submission mapping

## Location
Admin > Sourcing > Settings > Bid submission > Mapping

## Purpose
Controls the mapping applied when a bid submission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Use for high-volume tenants |
| Lenient | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |
| 60 minutes | Legacy behaviour |

## Impact of changes
Customers typically report this when a bid submission is processed in bulk or immediately after an administrator changes Sourcing settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-3139 and E-3398.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
