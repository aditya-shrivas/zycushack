# How to: Provision users in bulk

## Before you start
Customers typically report this when a record is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

## Steps
1. Sign in as a Platform administrator.
2. Go to Platform > Settings.
3. Select the option for: provision users in bulk.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
