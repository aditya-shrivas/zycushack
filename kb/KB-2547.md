# FAQ: Does the requisition support multiple currencies?

## Answer
Yes. An administrator can enable this under the module settings; the change applies to new records.

## Details
Customers typically report this when a requisition is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
