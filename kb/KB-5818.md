# Configuration reference: Payment file routing

## Location
Admin > eInvoice > Settings > Payment file > Routing

## Purpose
Controls the routing applied when a payment file is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Requires L2 enablement |
| Strict | Use for high-volume tenants |
| Global | Legacy behaviour |
| 60 minutes | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a payment file is processed in bulk or immediately after an administrator changes eInvoice settings. An incorrect value here is a common contributor to E-4385 and E-4320.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
