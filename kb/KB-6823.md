# Configuration reference: Erp sync job attachment limit

## Location
Admin > Integrations > Settings > Erp sync job > Attachment limit

## Purpose
Controls the attachment limit applied when a ERP sync job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Legacy behaviour |
| On | Legacy behaviour |
| Off | Recommended for most tenants |
| Strict | Requires L2 enablement |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-7397 and E-7271.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
