# Configuration reference: Tax validation numbering

## Location
Admin > eInvoice > Settings > Tax validation > Numbering

## Purpose
Controls the numbering applied when a tax validation is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Requires L2 enablement |
| 90 days | Recommended for most tenants |
| Lenient | Use for high-volume tenants |
| 60 minutes | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a tax validation is processed in bulk or immediately after an administrator changes eInvoice settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-4157 and E-4211.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
