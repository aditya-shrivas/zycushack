# Configuration reference: Invoice ocr job language

## Location
Admin > eInvoice > Settings > Invoice ocr job > Language

## Purpose
Controls the language applied when a invoice OCR job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Legacy behaviour |
| Strict | Legacy behaviour |
| On | Legacy behaviour |
| 5 minutes | Legacy behaviour |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a invoice OCR job is processed in bulk or immediately after an administrator changes eInvoice settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-4157 and E-4123.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
