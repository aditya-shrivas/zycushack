# Configuration reference: Bid submission attachment limit

## Location
Admin > Sourcing > Settings > Bid submission > Attachment limit

## Purpose
Controls the attachment limit applied when a bid submission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Requires L2 enablement |
| 30 days | Use for high-volume tenants |
| 5 minutes | Use for high-volume tenants |
| Lenient | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-3398 and E-3376.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
