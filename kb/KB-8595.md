# How to: Import master data

## Before you start
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Integrations settings.

## Steps
1. Sign in as a Integrations administrator.
2. Go to Integrations > Settings.
3. Select the option for: import master data.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
