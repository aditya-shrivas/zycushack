# FAQ: Does the supplier invitation support multiple currencies?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a supplier invitation is processed in bulk or immediately after an administrator changes Sourcing settings.
