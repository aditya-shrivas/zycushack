# E-7271: Webhook creates duplicate records

## Symptoms
Users see error **E-7271** when a webhook creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a stale configuration cache after a recent settings change.

## Resolution
1. Open Admin > System Tools and select Clear Configuration Cache.
2. Ask affected users to sign out and sign back in.
3. Retry the action.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a webhook is processed in bulk or immediately after an administrator changes Integrations settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.
