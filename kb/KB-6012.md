# How to: Configure tax validation rules

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

## Steps
1. Sign in as a eInvoice administrator.
2. Go to eInvoice > Settings.
3. Select the option for: configure tax validation rules.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
