# FAQ: How long is invoice approval history retained?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Customers typically report this when a invoice approval is processed in bulk or immediately after an administrator changes eInvoice settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
