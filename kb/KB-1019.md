# E-4384: Payment file creates duplicate records

## Symptoms
Users see error **E-4384** when a payment file creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a field mapping that does not match the tenant configuration.

## Resolution
1. Open Admin > Field Mapping and compare the source field list with the tenant schema.
2. Correct the mismatched field and save the mapping.
3. Re-run the failed transaction from the error queue.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
