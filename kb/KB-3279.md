# Configuration reference: User provisioning notification

## Location
Admin > Platform > Settings > User provisioning > Notification

## Purpose
Controls the notification applied when a user provisioning is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Use for high-volume tenants |
| Lenient | Use for high-volume tenants |
| 30 days | Requires L2 enablement |
| 90 days | Recommended for most tenants |

## Impact of changes
Customers typically report this when a user provisioning is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-8256 and E-8313.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
