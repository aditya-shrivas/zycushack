# Configuration reference: Clause library default

## Location
Admin > Contracts > Settings > Clause library > Default

## Purpose
Controls the default applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Requires L2 enablement |
| Strict | Requires L2 enablement |
| Lenient | Recommended for most tenants |
| On | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a clause library is processed in bulk or immediately after an administrator changes Contracts settings. An incorrect value here is a common contributor to E-2126 and E-2216.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
