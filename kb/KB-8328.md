# How to: Invite suppliers to an event

## Before you start
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement.

## Steps
1. Sign in as a Sourcing administrator.
2. Go to Sourcing > Settings.
3. Select the option for: invite suppliers to an event.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
