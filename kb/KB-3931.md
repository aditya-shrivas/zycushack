# Configuration reference: Clause library mapping

## Location
Admin > Contracts > Settings > Clause library > Mapping

## Purpose
Controls the mapping applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Recommended for most tenants |
| 15 minutes | Legacy behaviour |
| Strict | Legacy behaviour |
| Global | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-2109 and E-2185.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
