# Configuration reference: Credit memo default

## Location
Admin > eInvoice > Settings > Credit memo > Default

## Purpose
Controls the default applied when a credit memo is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Requires L2 enablement |
| Off | Recommended for most tenants |
| 15 minutes | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a credit memo is processed in bulk or immediately after an administrator changes eInvoice settings. An incorrect value here is a common contributor to E-4384 and E-4320.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
