# FAQ: How long is password reset history retained?

## Answer
Yes. An administrator can enable this under the module settings; the change applies to new records.

## Details
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a password reset is processed in bulk or immediately after an administrator changes Platform settings.

Customers typically report this when a password reset is processed in bulk or immediately after an administrator changes Platform settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.
