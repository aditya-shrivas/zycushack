# How to: Upload invoices for OCR

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a record is processed in bulk or immediately after an administrator changes eInvoice settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a eInvoice administrator.
2. Go to eInvoice > Settings.
3. Select the option for: upload invoices for ocr.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
