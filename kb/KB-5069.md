# Configuration reference: Saml assertion visibility

## Location
Admin > Platform > Settings > Saml assertion > Visibility

## Purpose
Controls the visibility applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Legacy behaviour |
| On | Legacy behaviour |
| 90 days | Requires L2 enablement |
| Lenient | Use for high-volume tenants |

## Impact of changes
Customers typically report this when a SAML assertion is processed in bulk or immediately after an administrator changes Platform settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-8205 and E-8274.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
