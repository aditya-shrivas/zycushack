# How to: Set up SFTP file transfer

## Before you start
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

## Steps
1. Sign in as a Integrations administrator.
2. Go to Integrations > Settings.
3. Select the option for: set up sftp file transfer.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
