# Configuration reference: Supplier invitation visibility

## Location
Admin > Sourcing > Settings > Supplier invitation > Visibility

## Purpose
Controls the visibility applied when a supplier invitation is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Use for high-volume tenants |
| 90 days | Requires L2 enablement |
| 15 minutes | Use for high-volume tenants |
| Off | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-3185 and E-3115.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
