# Configuration reference: Rfx event numbering

## Location
Admin > Sourcing > Settings > Rfx event > Numbering

## Purpose
Controls the numbering applied when a RFx event is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Use for high-volume tenants |
| 5 minutes | Recommended for most tenants |
| Per business unit | Requires L2 enablement |
| 30 days | Legacy behaviour |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-3216 and E-3276.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
