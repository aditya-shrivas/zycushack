# FAQ: How long is approval workflow history retained?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a approval workflow is processed in bulk or immediately after an administrator changes eProcurement settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
