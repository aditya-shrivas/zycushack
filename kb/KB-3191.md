# [DEPRECATED] E-7249: Erp sync job shows incorrect values

> This article is deprecated and kept for audit history only. It describes behaviour on release 24.x. See KB-1369 for the current procedure.

## Symptoms
Users see error **E-7249** when a ERP sync job shows incorrect values.

## Cause (release 24.x)
Browser plug-in incompatibility.

## Resolution (release 24.x)
1. Ask the customer to clear the browser cache and retry.
2. If the error persists, reinstall the legacy browser plug-in.
3. Raise an L2 ticket if the error persists after 24 hours.
