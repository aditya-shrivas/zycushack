# FAQ: Can a API token be restored after deletion?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
