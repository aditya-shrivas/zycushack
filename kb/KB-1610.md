# Configuration reference: Purchase order visibility

## Location
Admin > eProcurement > Settings > Purchase order > Visibility

## Purpose
Controls the visibility applied when a purchase order is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Recommended for most tenants |
| On | Use for high-volume tenants |
| 30 days | Requires L2 enablement |
| 15 minutes | Use for high-volume tenants |

## Impact of changes
Customers typically report this when a purchase order is processed in bulk or immediately after an administrator changes eProcurement settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-1281 and E-1263.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
