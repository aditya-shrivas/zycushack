# Configuration reference: Punch-out session notification

## Location
Admin > eProcurement > Settings > Punch-out session > Notification

## Purpose
Controls the notification applied when a punch-out session is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Use for high-volume tenants |
| 60 minutes | Recommended for most tenants |
| On | Recommended for most tenants |
| Off | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-1101 and E-1287.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
