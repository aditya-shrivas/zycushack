# E-4329: Invoice approval returns a validation error

## Symptoms
Users see error **E-4329** when a invoice approval returns a validation error. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a stale configuration cache after a recent settings change.

## Resolution
1. Open Admin > System Tools and select Clear Configuration Cache.
2. Ask affected users to sign out and sign back in.
3. Retry the action.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a invoice approval is processed in bulk or immediately after an administrator changes eInvoice settings. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
