# Configuration reference: Master data import routing

## Location
Admin > Integrations > Settings > Master data import > Routing

## Purpose
Controls the routing applied when a master data import is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Recommended for most tenants |
| 60 minutes | Requires L2 enablement |
| Strict | Legacy behaviour |
| Off | Use for high-volume tenants |

## Impact of changes
Customers typically report this when a master data import is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-7336 and E-7342.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
