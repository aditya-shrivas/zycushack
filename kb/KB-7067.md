# Configuration reference: Contract template visibility

## Location
Admin > Contracts > Settings > Contract template > Visibility

## Purpose
Controls the visibility applied when a contract template is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Use for high-volume tenants |
| 30 days | Use for high-volume tenants |
| 5 minutes | Requires L2 enablement |
| On | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a contract template is processed in bulk or immediately after an administrator changes Contracts settings. An incorrect value here is a common contributor to E-2378 and E-2326.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
