# Configuration reference: Api token tolerance

## Location
Admin > Integrations > Settings > Api token > Tolerance

## Purpose
Controls the tolerance applied when a API token is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Recommended for most tenants |
| 5 minutes | Requires L2 enablement |
| 60 minutes | Use for high-volume tenants |
| Global | Requires L2 enablement |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a API token is processed in bulk or immediately after an administrator changes Integrations settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-7308 and E-7204.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
