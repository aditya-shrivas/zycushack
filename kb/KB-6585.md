# Configuration reference: Catalog item default

## Location
Admin > eProcurement > Settings > Catalog item > Default

## Purpose
Controls the default applied when a catalog item is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Requires L2 enablement |
| Off | Recommended for most tenants |
| Global | Requires L2 enablement |
| Lenient | Requires L2 enablement |

## Impact of changes
Customers typically report this when a catalog item is processed in bulk or immediately after an administrator changes eProcurement settings. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-1287 and E-1263.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
