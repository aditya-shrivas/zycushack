# How to: Configure punch-out catalogs

## Before you start
Customers typically report this when a record is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement.

## Steps
1. Sign in as a eProcurement administrator.
2. Go to eProcurement > Settings.
3. Select the option for: configure punch-out catalogs.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
