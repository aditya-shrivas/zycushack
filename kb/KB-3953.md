# Configuration reference: Renewal alert timeout

## Location
Admin > Contracts > Settings > Renewal alert > Timeout

## Purpose
Controls the timeout applied when a renewal alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Requires L2 enablement |
| 5 minutes | Recommended for most tenants |
| 30 days | Use for high-volume tenants |
| 60 minutes | Requires L2 enablement |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-2109 and E-2126.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
