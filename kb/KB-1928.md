# FAQ: Why does the compliance document show a different status for some users?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a compliance document is processed in bulk or immediately after an administrator changes Supplier Management settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
