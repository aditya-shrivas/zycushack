# Configuration reference: Award recommendation threshold

## Location
Admin > Sourcing > Settings > Award recommendation > Threshold

## Purpose
Controls the threshold applied when a award recommendation is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Recommended for most tenants |
| Global | Legacy behaviour |
| 15 minutes | Requires L2 enablement |
| On | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a award recommendation is processed in bulk or immediately after an administrator changes Sourcing settings. An incorrect value here is a common contributor to E-3126 and E-3216.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
