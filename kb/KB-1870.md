# Configuration reference: Certificate expiry alert attachment limit

## Location
Admin > Supplier Management > Settings > Certificate expiry alert > Attachment limit

## Purpose
Controls the attachment limit applied when a certificate expiry alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| Global | Recommended for most tenants |
| Strict | Requires L2 enablement |
| 30 days | Legacy behaviour |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-5104 and E-5379.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
