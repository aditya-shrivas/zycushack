# Configuration reference: User provisioning timeout

## Location
Admin > Platform > Settings > User provisioning > Timeout

## Purpose
Controls the timeout applied when a user provisioning is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Legacy behaviour |
| Global | Use for high-volume tenants |
| 90 days | Legacy behaviour |
| 5 minutes | Legacy behaviour |

## Impact of changes
Customers typically report this when a user provisioning is processed in bulk or immediately after an administrator changes Platform settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-8143 and E-8173.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
