# Configuration reference: Role permission default

## Location
Admin > Platform > Settings > Role permission > Default

## Purpose
Controls the default applied when a role permission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| 30 days | Legacy behaviour |
| 15 minutes | Legacy behaviour |
| 90 days | Legacy behaviour |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-8205 and E-8256.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
