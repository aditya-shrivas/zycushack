# Configuration reference: Payment file retention

## Location
Admin > eInvoice > Settings > Payment file > Retention

## Purpose
Controls the retention applied when a payment file is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Recommended for most tenants |
| On | Legacy behaviour |
| 15 minutes | Legacy behaviour |
| Per business unit | Requires L2 enablement |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a payment file is processed in bulk or immediately after an administrator changes eInvoice settings. An incorrect value here is a common contributor to E-4144 and E-4320.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
