# Configuration reference: Contract template validation

## Location
Admin > Contracts > Settings > Contract template > Validation

## Purpose
Controls the validation applied when a contract template is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Legacy behaviour |
| Strict | Requires L2 enablement |
| 30 days | Legacy behaviour |
| 15 minutes | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-2378 and E-2185.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
