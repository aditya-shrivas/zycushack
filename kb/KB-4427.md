# E-2126: Renewal alert does not trigger

## Symptoms
Users see error **E-2126** when a renewal alert does not trigger. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by an exchange-rate table that was not refreshed.

## Resolution
1. Open Admin > Currency and check the last refresh date.
2. Run Refresh Rates now.
3. Re-run the affected calculation or report.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement.
