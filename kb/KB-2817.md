# Configuration reference: Dashboard mapping

## Location
Admin > Spend Analytics > Settings > Dashboard > Mapping

## Purpose
Controls the mapping applied when a dashboard is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Recommended for most tenants |
| 90 days | Recommended for most tenants |
| Strict | Use for high-volume tenants |
| Per business unit | Requires L2 enablement |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-6314 and E-6295.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
