# Configuration reference: Catalog item validation

## Location
Admin > eProcurement > Settings > Catalog item > Validation

## Purpose
Controls the validation applied when a catalog item is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |
| Off | Legacy behaviour |
| Per business unit | Requires L2 enablement |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a catalog item is processed in bulk or immediately after an administrator changes eProcurement settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-1263 and E-1287.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
