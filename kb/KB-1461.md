# Configuration reference: Bid submission timeout

## Location
Admin > Sourcing > Settings > Bid submission > Timeout

## Purpose
Controls the timeout applied when a bid submission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Use for high-volume tenants |
| Lenient | Recommended for most tenants |
| Global | Use for high-volume tenants |
| 30 days | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-3139 and E-3185.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
