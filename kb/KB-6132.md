# Configuration reference: Reverse auction currency

## Location
Admin > Sourcing > Settings > Reverse auction > Currency

## Purpose
Controls the currency applied when a reverse auction is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Legacy behaviour |
| 30 days | Use for high-volume tenants |
| Per business unit | Recommended for most tenants |
| On | Requires L2 enablement |

## Impact of changes
Customers typically report this when a reverse auction is processed in bulk or immediately after an administrator changes Sourcing settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-3126 and E-3139.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
