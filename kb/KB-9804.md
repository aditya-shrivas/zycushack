# Configuration reference: Risk questionnaire timeout

## Location
Admin > Supplier Management > Settings > Risk questionnaire > Timeout

## Purpose
Controls the timeout applied when a risk questionnaire is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Use for high-volume tenants |
| 30 days | Recommended for most tenants |
| Off | Recommended for most tenants |
| 60 minutes | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a risk questionnaire is processed in bulk or immediately after an administrator changes Supplier Management settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-5367 and E-5104.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
