# Configuration reference: Webhook frequency

## Location
Admin > Integrations > Settings > Webhook > Frequency

## Purpose
Controls the frequency applied when a webhook is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Recommended for most tenants |
| 30 days | Legacy behaviour |
| 15 minutes | Legacy behaviour |
| Strict | Requires L2 enablement |

## Impact of changes
Customers typically report this when a webhook is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-7204 and E-7271.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
