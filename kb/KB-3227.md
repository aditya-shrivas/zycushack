# Configuration reference: Master data import retention

## Location
Admin > Integrations > Settings > Master data import > Retention

## Purpose
Controls the retention applied when a master data import is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Recommended for most tenants |
| Off | Legacy behaviour |
| 30 days | Legacy behaviour |
| Lenient | Recommended for most tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-7271 and E-7336.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
