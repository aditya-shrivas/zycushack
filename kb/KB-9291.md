# Configuration reference: Contract template language

## Location
Admin > Contracts > Settings > Contract template > Language

## Purpose
Controls the language applied when a contract template is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| 30 days | Use for high-volume tenants |
| Lenient | Recommended for most tenants |
| 15 minutes | Legacy behaviour |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-2109 and E-2378.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
