# Configuration reference: Catalog item threshold

## Location
Admin > eProcurement > Settings > Catalog item > Threshold

## Purpose
Controls the threshold applied when a catalog item is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Recommended for most tenants |
| 5 minutes | Use for high-volume tenants |
| Per business unit | Recommended for most tenants |
| 90 days | Requires L2 enablement |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-1173 and E-1172.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
