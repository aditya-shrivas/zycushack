# Configuration reference: 3-way match notification

## Location
Admin > eInvoice > Settings > 3-way match > Notification

## Purpose
Controls the notification applied when a 3-way match is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Use for high-volume tenants |
| 60 minutes | Legacy behaviour |
| Per business unit | Requires L2 enablement |
| On | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a 3-way match is processed in bulk or immediately after an administrator changes eInvoice settings. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-4384 and E-4256.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
