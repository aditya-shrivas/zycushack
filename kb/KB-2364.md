# Configuration reference: Rfx event routing

## Location
Admin > Sourcing > Settings > Rfx event > Routing

## Purpose
Controls the routing applied when a RFx event is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Requires L2 enablement |
| Global | Requires L2 enablement |
| Off | Use for high-volume tenants |
| Per business unit | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a RFx event is processed in bulk or immediately after an administrator changes Sourcing settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-3216 and E-3376.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
