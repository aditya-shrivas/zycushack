# Configuration reference: Data export language

## Location
Admin > Spend Analytics > Settings > Data export > Language

## Purpose
Controls the language applied when a data export is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Legacy behaviour |
| Lenient | Requires L2 enablement |
| 15 minutes | Use for high-volume tenants |
| Per business unit | Legacy behaviour |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a data export is processed in bulk or immediately after an administrator changes Spend Analytics settings. An incorrect value here is a common contributor to E-6182 and E-6159.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
