# Configuration reference: Dashboard attachment limit

## Location
Admin > Spend Analytics > Settings > Dashboard > Attachment limit

## Purpose
Controls the attachment limit applied when a dashboard is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Requires L2 enablement |
| Per business unit | Legacy behaviour |
| Off | Use for high-volume tenants |
| On | Requires L2 enablement |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-6285 and E-6182.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
