# Configuration reference: Role permission threshold

## Location
Admin > Platform > Settings > Role permission > Threshold

## Purpose
Controls the threshold applied when a role permission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Requires L2 enablement |
| 60 minutes | Legacy behaviour |
| Per business unit | Requires L2 enablement |
| Global | Requires L2 enablement |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-8175 and E-8313.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
