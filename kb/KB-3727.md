# Configuration reference: Saml assertion frequency

## Location
Admin > Platform > Settings > Saml assertion > Frequency

## Purpose
Controls the frequency applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Recommended for most tenants |
| 5 minutes | Requires L2 enablement |
| 90 days | Requires L2 enablement |
| Global | Legacy behaviour |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-8225 and E-8174.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
