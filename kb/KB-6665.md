# FAQ: How long is clause library history retained?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a clause library is processed in bulk or immediately after an administrator changes Contracts settings. Most cases are resolved by a tenant administrator without engineering involvement.
