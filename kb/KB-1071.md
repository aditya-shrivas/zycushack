# Configuration reference: Password reset language

## Location
Admin > Platform > Settings > Password reset > Language

## Purpose
Controls the language applied when a password reset is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Recommended for most tenants |
| Global | Recommended for most tenants |
| Per business unit | Legacy behaviour |
| Lenient | Requires L2 enablement |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-8274 and E-8175.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
