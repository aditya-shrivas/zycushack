# Configuration reference: Saml assertion currency

## Location
Admin > Platform > Settings > Saml assertion > Currency

## Purpose
Controls the currency applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Legacy behaviour |
| 90 days | Legacy behaviour |
| Global | Recommended for most tenants |
| 15 minutes | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-8175 and E-8274.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
