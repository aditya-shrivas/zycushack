# FAQ: How long is SSO login history retained?

## Answer
Retention follows the tenant's data retention policy, which is 7 years by default.

## Details
Customers typically report this when a SSO login is processed in bulk or immediately after an administrator changes Platform settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.
