# How to: Configure SSO with SAML 2.0

## Before you start
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a Platform administrator.
2. Go to Platform > Settings.
3. Select the option for: configure sso with saml 2.0.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
