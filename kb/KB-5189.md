# Configuration reference: Master data import threshold

## Location
Admin > Integrations > Settings > Master data import > Threshold

## Purpose
Controls the threshold applied when a master data import is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Requires L2 enablement |
| Per business unit | Use for high-volume tenants |
| 15 minutes | Recommended for most tenants |
| Off | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-7172 and E-7249.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
