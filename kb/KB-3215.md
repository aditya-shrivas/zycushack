# Configuration reference: Punch-out session language

## Location
Admin > eProcurement > Settings > Punch-out session > Language

## Purpose
Controls the language applied when a punch-out session is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Legacy behaviour |
| 90 days | Recommended for most tenants |
| Off | Legacy behaviour |
| Global | Use for high-volume tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a punch-out session is processed in bulk or immediately after an administrator changes eProcurement settings. An incorrect value here is a common contributor to E-1115 and E-1198.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
