# Configuration reference: Reverse auction notification

## Location
Admin > Sourcing > Settings > Reverse auction > Notification

## Purpose
Controls the notification applied when a reverse auction is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Use for high-volume tenants |
| 15 minutes | Use for high-volume tenants |
| 60 minutes | Recommended for most tenants |
| 30 days | Use for high-volume tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-3216 and E-3398.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
