# Configuration reference: Credit memo currency

## Location
Admin > eInvoice > Settings > Credit memo > Currency

## Purpose
Controls the currency applied when a credit memo is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Recommended for most tenants |
| 15 minutes | Legacy behaviour |
| 60 minutes | Requires L2 enablement |
| 90 days | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-4385 and E-4320.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
