# E-8274: Password reset stays stuck in processing

## Symptoms
Users see error **E-8274** when a password reset stays stuck in processing. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a field mapping that does not match the tenant configuration.

## Resolution
1. Open Admin > Field Mapping and compare the source field list with the tenant schema.
2. Correct the mismatched field and save the mapping.
3. Re-run the failed transaction from the error queue.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a password reset is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
