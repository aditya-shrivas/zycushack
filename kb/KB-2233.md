# Configuration reference: Sftp file transfer currency

## Location
Admin > Integrations > Settings > Sftp file transfer > Currency

## Purpose
Controls the currency applied when a SFTP file transfer is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Use for high-volume tenants |
| 60 minutes | Recommended for most tenants |
| 30 days | Legacy behaviour |
| 90 days | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a SFTP file transfer is processed in bulk or immediately after an administrator changes Integrations settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-7141 and E-7336.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
