# FAQ: How long is webhook history retained?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Customers typically report this when a webhook is processed in bulk or immediately after an administrator changes Integrations settings. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
