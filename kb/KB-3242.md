# FAQ: How long is data load history retained?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement.

Customers typically report this when a data load is processed in bulk or immediately after an administrator changes Spend Analytics settings.
