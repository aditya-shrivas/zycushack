# Configuration reference: Api token default

## Location
Admin > Integrations > Settings > Api token > Default

## Purpose
Controls the default applied when a API token is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Use for high-volume tenants |
| Lenient | Legacy behaviour |
| Strict | Recommended for most tenants |
| 90 days | Recommended for most tenants |

## Impact of changes
Customers typically report this when a API token is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-7252 and E-7336.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
