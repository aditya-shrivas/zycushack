# How to: Bulk-approve purchase orders

## Before you start
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a record is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

## Steps
1. Sign in as a eProcurement administrator.
2. Go to eProcurement > Settings.
3. Select the option for: bulk-approve purchase orders.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
