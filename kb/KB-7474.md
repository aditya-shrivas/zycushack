# E-5289: Compliance document stays stuck in processing

## Symptoms
Users see error **E-5289** when a compliance document stays stuck in processing. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a defect introduced in release 26.2.

## Resolution
1. Apply the workaround documented in the release notes for 26.2.
2. Raise an L2 ticket referencing this article if the workaround fails.
3. Monitor for the hotfix announcement.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a compliance document is processed in bulk or immediately after an administrator changes Supplier Management settings. Most cases are resolved by a tenant administrator without engineering involvement.
