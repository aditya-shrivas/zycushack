# Configuration reference: Compliance document routing

## Location
Admin > Supplier Management > Settings > Compliance document > Routing

## Purpose
Controls the routing applied when a compliance document is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Use for high-volume tenants |
| Global | Requires L2 enablement |
| 60 minutes | Use for high-volume tenants |
| Strict | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a compliance document is processed in bulk or immediately after an administrator changes Supplier Management settings. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-5289 and E-5148.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
