# How to: Create custom roles

## Before you start
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

## Steps
1. Sign in as a Platform administrator.
2. Go to Platform > Settings.
3. Select the option for: create custom roles.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
