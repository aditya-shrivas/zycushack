# FAQ: Can we export data export data on a schedule?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
