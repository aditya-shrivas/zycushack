# E-7252: Sftp file transfer creates duplicate records

## Symptoms
Users see error **E-7252** when a SFTP file transfer creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a missing role permission for the acting user.

## Resolution
1. Open Admin > Roles and locate the role of the affected user.
2. Grant the permission listed in the error detail.
3. Ask the user to refresh the session and retry.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a SFTP file transfer is processed in bulk or immediately after an administrator changes Integrations settings. Most cases are resolved by a tenant administrator without engineering involvement.
