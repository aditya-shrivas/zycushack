# How to: Create a requisition from a catalog

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a record is processed in bulk or immediately after an administrator changes eProcurement settings.

## Steps
1. Sign in as a eProcurement administrator.
2. Go to eProcurement > Settings.
3. Select the option for: create a requisition from a catalog.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
