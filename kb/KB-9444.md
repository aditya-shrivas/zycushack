# How to: Compare redline versions

## Before you start
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Contracts settings.

## Steps
1. Sign in as a Contracts administrator.
2. Go to Contracts > Settings.
3. Select the option for: compare redline versions.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
