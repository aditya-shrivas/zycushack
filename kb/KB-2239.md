# FAQ: Does the budget check support multiple currencies?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement.

Customers typically report this when a budget check is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
