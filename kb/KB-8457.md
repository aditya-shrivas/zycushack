# E-2216: Clause library creates duplicate records

## Symptoms
Users see error **E-2216** when a clause library creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a paused background scheduler job.

## Resolution
1. Open Admin > Scheduler and locate the paused job.
2. Resume the job and run it once manually.
3. Confirm downstream records update within 15 minutes.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a clause library is processed in bulk or immediately after an administrator changes Contracts settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
