# FAQ: Can a password reset be restored after deletion?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Customers typically report this when a password reset is processed in bulk or immediately after an administrator changes Platform settings. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.

This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
