# Configuration reference: Certificate expiry alert frequency

## Location
Admin > Supplier Management > Settings > Certificate expiry alert > Frequency

## Purpose
Controls the frequency applied when a certificate expiry alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Legacy behaviour |
| Off | Requires L2 enablement |
| 60 minutes | Requires L2 enablement |
| Strict | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a certificate expiry alert is processed in bulk or immediately after an administrator changes Supplier Management settings. An incorrect value here is a common contributor to E-5176 and E-5327.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
