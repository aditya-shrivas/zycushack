# Configuration reference: Compliance document tolerance

## Location
Admin > Supplier Management > Settings > Compliance document > Tolerance

## Purpose
Controls the tolerance applied when a compliance document is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Legacy behaviour |
| 60 minutes | Requires L2 enablement |
| Global | Recommended for most tenants |
| 90 days | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a compliance document is processed in bulk or immediately after an administrator changes Supplier Management settings. An incorrect value here is a common contributor to E-5176 and E-5370.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
