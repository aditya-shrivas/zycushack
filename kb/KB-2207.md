# Configuration reference: Purchase order timeout

## Location
Admin > eProcurement > Settings > Purchase order > Timeout

## Purpose
Controls the timeout applied when a purchase order is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Recommended for most tenants |
| Lenient | Legacy behaviour |
| 15 minutes | Requires L2 enablement |
| Global | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-1115 and E-1101.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
