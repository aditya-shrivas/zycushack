# Configuration reference: Saml assertion tolerance

## Location
Admin > Platform > Settings > Saml assertion > Tolerance

## Purpose
Controls the tolerance applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Recommended for most tenants |
| 15 minutes | Requires L2 enablement |
| Off | Recommended for most tenants |
| Lenient | Requires L2 enablement |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a SAML assertion is processed in bulk or immediately after an administrator changes Platform settings. An incorrect value here is a common contributor to E-8274 and E-8143.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
