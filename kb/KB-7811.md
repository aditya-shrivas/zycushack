# Configuration reference: Saml assertion numbering

## Location
Admin > Platform > Settings > Saml assertion > Numbering

## Purpose
Controls the numbering applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Requires L2 enablement |
| Per business unit | Legacy behaviour |
| On | Legacy behaviour |
| Global | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a SAML assertion is processed in bulk or immediately after an administrator changes Platform settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-8174 and E-8313.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
