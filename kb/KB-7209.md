# FAQ: Why does the certificate expiry alert show a different status for some users?

## Answer
Yes. An administrator can enable this under the module settings; the change applies to new records.

## Details
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.

Customers typically report this when a certificate expiry alert is processed in bulk or immediately after an administrator changes Supplier Management settings. Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
