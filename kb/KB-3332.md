# Configuration reference: Api token validation

## Location
Admin > Integrations > Settings > Api token > Validation

## Purpose
Controls the validation applied when a API token is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Use for high-volume tenants |
| 90 days | Recommended for most tenants |
| 5 minutes | Legacy behaviour |
| Global | Legacy behaviour |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a API token is processed in bulk or immediately after an administrator changes Integrations settings. An incorrect value here is a common contributor to E-7308 and E-7397.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
