# How to: Track contract obligations

## Before you start
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a Contracts administrator.
2. Go to Contracts > Settings.
3. Select the option for: track contract obligations.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
