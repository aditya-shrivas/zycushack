# Identifying duplicate tickets

A ticket is a duplicate when the same account has an open or pending ticket for the same module and the same error code or symptom created within the previous 7 days.

## Handling
- Set duplicate_of to the original ticket ID.
- Keep the original ticket's priority. Do not re-escalate.
- Reply that the issue is being tracked on the original ticket and share its current status.
