# FAQ: Why does the session show a different status for some users?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
Customers typically report this when a session is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
