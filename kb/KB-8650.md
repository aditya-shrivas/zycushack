# Configuration reference: Classification job validation

## Location
Admin > Spend Analytics > Settings > Classification job > Validation

## Purpose
Controls the validation applied when a classification job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Legacy behaviour |
| 5 minutes | Legacy behaviour |
| Off | Use for high-volume tenants |
| Strict | Legacy behaviour |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a classification job is processed in bulk or immediately after an administrator changes Spend Analytics settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-6258 and E-6159.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
