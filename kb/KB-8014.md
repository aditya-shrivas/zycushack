# FAQ: Can we export ERP sync job data on a schedule?

## Answer
Yes. An administrator can enable this under the module settings; the change applies to new records.

## Details
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a ERP sync job is processed in bulk or immediately after an administrator changes Integrations settings.
