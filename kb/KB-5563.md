# Configuration reference: Approval workflow numbering

## Location
Admin > eProcurement > Settings > Approval workflow > Numbering

## Purpose
Controls the numbering applied when a approval workflow is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Use for high-volume tenants |
| 90 days | Recommended for most tenants |
| Off | Legacy behaviour |
| Per business unit | Requires L2 enablement |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-1172 and E-1173.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
