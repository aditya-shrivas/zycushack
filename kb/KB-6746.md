# Configuration reference: Webhook mapping

## Location
Admin > Integrations > Settings > Webhook > Mapping

## Purpose
Controls the mapping applied when a webhook is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Use for high-volume tenants |
| 60 minutes | Recommended for most tenants |
| 15 minutes | Legacy behaviour |
| Strict | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a webhook is processed in bulk or immediately after an administrator changes Integrations settings. An incorrect value here is a common contributor to E-7271 and E-7249.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
