# E-2138: Clause library is rejected

## Symptoms
Users see error **E-2138** when a clause library is rejected. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a time-zone mismatch between the ERP and the tenant.

## Resolution
1. Compare the ERP server time zone with Admin > Tenant Settings > Time Zone.
2. Align both to the same zone.
3. Reprocess records from the affected window.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement.
