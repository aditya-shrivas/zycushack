# Configuration reference: Credit memo validation

## Location
Admin > eInvoice > Settings > Credit memo > Validation

## Purpose
Controls the validation applied when a credit memo is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Recommended for most tenants |
| 90 days | Legacy behaviour |
| 30 days | Requires L2 enablement |
| 60 minutes | Requires L2 enablement |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a credit memo is processed in bulk or immediately after an administrator changes eInvoice settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-4123 and E-4157.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
