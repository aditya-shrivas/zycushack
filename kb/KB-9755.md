# FAQ: Can a supplier onboarding form be restored after deletion?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a supplier onboarding form is processed in bulk or immediately after an administrator changes Supplier Management settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
