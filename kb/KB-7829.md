# Configuration reference: E-signature request tolerance

## Location
Admin > Contracts > Settings > E-signature request > Tolerance

## Purpose
Controls the tolerance applied when a e-signature request is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Requires L2 enablement |
| 60 minutes | Requires L2 enablement |
| 15 minutes | Requires L2 enablement |
| Strict | Legacy behaviour |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a e-signature request is processed in bulk or immediately after an administrator changes Contracts settings. An incorrect value here is a common contributor to E-2216 and E-2185.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
