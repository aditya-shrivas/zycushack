# Configuration reference: Renewal alert threshold

## Location
Admin > Contracts > Settings > Renewal alert > Threshold

## Purpose
Controls the threshold applied when a renewal alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Use for high-volume tenants |
| On | Requires L2 enablement |
| 90 days | Use for high-volume tenants |
| Lenient | Legacy behaviour |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a renewal alert is processed in bulk or immediately after an administrator changes Contracts settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-2185 and E-2159.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
