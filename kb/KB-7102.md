# E-6213: Data export returns a validation error

## Symptoms
Users see error **E-6213** when a data export returns a validation error. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by an exchange-rate table that was not refreshed.

## Resolution
1. Open Admin > Currency and check the last refresh date.
2. Run Refresh Rates now.
3. Re-run the affected calculation or report.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a data export is processed in bulk or immediately after an administrator changes Spend Analytics settings.
