# Configuration reference: Clause library numbering

## Location
Admin > Contracts > Settings > Clause library > Numbering

## Purpose
Controls the numbering applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Recommended for most tenants |
| 60 minutes | Legacy behaviour |
| Off | Recommended for most tenants |
| Lenient | Recommended for most tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-2156 and E-2159.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
