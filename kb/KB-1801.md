# Configuration reference: Currency conversion frequency

## Location
Admin > Spend Analytics > Settings > Currency conversion > Frequency

## Purpose
Controls the frequency applied when a currency conversion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Requires L2 enablement |
| 90 days | Requires L2 enablement |
| 15 minutes | Legacy behaviour |
| Per business unit | Requires L2 enablement |

## Impact of changes
Customers typically report this when a currency conversion is processed in bulk or immediately after an administrator changes Spend Analytics settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-6258 and E-6169.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
