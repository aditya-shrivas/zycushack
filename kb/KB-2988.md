# FAQ: Can a renewal alert be restored after deletion?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
Customers typically report this when a renewal alert is processed in bulk or immediately after an administrator changes Contracts settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
