# E-7141: Sftp file transfer times out

## Symptoms
Users see error **E-7141** when a SFTP file transfer times out. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a workflow rule referencing an inactive approver group.

## Resolution
1. Open the workflow rule named in the error detail.
2. Replace the inactive approver group with an active group.
3. Re-route stuck documents from Workflow > Pending.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a SFTP file transfer is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
