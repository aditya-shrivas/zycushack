# How to: Schedule a spend cube refresh

## Before you start
Customers typically report this when a record is processed in bulk or immediately after an administrator changes Spend Analytics settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a Spend Analytics administrator.
2. Go to Spend Analytics > Settings.
3. Select the option for: schedule a spend cube refresh.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
