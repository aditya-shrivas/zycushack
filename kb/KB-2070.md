# Configuration reference: Rfx event frequency

## Location
Admin > Sourcing > Settings > Rfx event > Frequency

## Purpose
Controls the frequency applied when a RFx event is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Use for high-volume tenants |
| On | Recommended for most tenants |
| Off | Legacy behaviour |
| Global | Use for high-volume tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a RFx event is processed in bulk or immediately after an administrator changes Sourcing settings. An incorrect value here is a common contributor to E-3139 and E-3216.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
