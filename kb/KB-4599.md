# Configuration reference: Budget check frequency

## Location
Admin > eProcurement > Settings > Budget check > Frequency

## Purpose
Controls the frequency applied when a budget check is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Legacy behaviour |
| Lenient | Use for high-volume tenants |
| Strict | Legacy behaviour |
| 90 days | Recommended for most tenants |

## Impact of changes
Customers typically report this when a budget check is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-1325 and E-1198.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
