# How to: Reset a user password

## Before you start
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement.

## Steps
1. Sign in as a Platform administrator.
2. Go to Platform > Settings.
3. Select the option for: reset a user password.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
