# How to: Configure renewal alerts

## Before you start
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Contracts settings. Most cases are resolved by a tenant administrator without engineering involvement.

## Steps
1. Sign in as a Contracts administrator.
2. Go to Contracts > Settings.
3. Select the option for: configure renewal alerts.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
