# Configuration reference: Invoice ocr job visibility

## Location
Admin > eInvoice > Settings > Invoice ocr job > Visibility

## Purpose
Controls the visibility applied when a invoice OCR job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Use for high-volume tenants |
| 90 days | Legacy behaviour |
| Global | Legacy behaviour |
| Strict | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a invoice OCR job is processed in bulk or immediately after an administrator changes eInvoice settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-4144 and E-4157.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
