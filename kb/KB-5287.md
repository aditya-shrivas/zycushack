# Configuration reference: Bank detail change language

## Location
Admin > Supplier Management > Settings > Bank detail change > Language

## Purpose
Controls the language applied when a bank detail change is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Use for high-volume tenants |
| 15 minutes | Use for high-volume tenants |
| 5 minutes | Recommended for most tenants |
| 60 minutes | Requires L2 enablement |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-5148 and E-5289.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
