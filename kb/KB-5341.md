# FAQ: Who receives notifications for a catalog item?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
Customers typically report this when a catalog item is processed in bulk or immediately after an administrator changes eProcurement settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.

Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
