# Configuration reference: Sftp file transfer numbering

## Location
Admin > Integrations > Settings > Sftp file transfer > Numbering

## Purpose
Controls the numbering applied when a SFTP file transfer is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Legacy behaviour |
| 60 minutes | Legacy behaviour |
| 15 minutes | Legacy behaviour |
| 30 days | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a SFTP file transfer is processed in bulk or immediately after an administrator changes Integrations settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-7141 and E-7308.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
