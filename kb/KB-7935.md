# Configuration reference: Erp sync job visibility

## Location
Admin > Integrations > Settings > Erp sync job > Visibility

## Purpose
Controls the visibility applied when a ERP sync job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Legacy behaviour |
| Strict | Requires L2 enablement |
| On | Use for high-volume tenants |
| 15 minutes | Use for high-volume tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-7252 and E-7397.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
