# Configuration reference: Clause library retention

## Location
Admin > Contracts > Settings > Clause library > Retention

## Purpose
Controls the retention applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Use for high-volume tenants |
| Lenient | Recommended for most tenants |
| 15 minutes | Requires L2 enablement |
| 5 minutes | Legacy behaviour |

## Impact of changes
Customers typically report this when a clause library is processed in bulk or immediately after an administrator changes Contracts settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-2156 and E-2216.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
