# Configuration reference: Tax validation mapping

## Location
Admin > eInvoice > Settings > Tax validation > Mapping

## Purpose
Controls the mapping applied when a tax validation is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Lenient | Use for high-volume tenants |
| Strict | Legacy behaviour |
| 30 days | Recommended for most tenants |
| 15 minutes | Recommended for most tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-4144 and E-4123.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
