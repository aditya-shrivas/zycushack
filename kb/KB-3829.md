# Configuration reference: Payment file threshold

## Location
Admin > eInvoice > Settings > Payment file > Threshold

## Purpose
Controls the threshold applied when a payment file is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Legacy behaviour |
| Per business unit | Recommended for most tenants |
| 15 minutes | Requires L2 enablement |
| 90 days | Use for high-volume tenants |

## Impact of changes
Customers typically report this when a payment file is processed in bulk or immediately after an administrator changes eInvoice settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-4320 and E-4384.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
