# E-1173: Budget check times out

## Symptoms
Users see error **E-1173** when a budget check times out. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by an expired integration credential.

## Resolution
1. Open Admin > Integrations > Credentials.
2. Regenerate the credential and update it in the connected system.
3. Trigger a manual sync and confirm the job status shows Completed.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.
