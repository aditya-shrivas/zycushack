# FAQ: Can we export supplier profile data on a schedule?

## Answer
This depends on the role configuration. Review the role's permissions in Admin > Roles.

## Details
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a supplier profile is processed in bulk or immediately after an administrator changes Supplier Management settings.
