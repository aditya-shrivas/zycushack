# Configuration reference: Risk questionnaire validation

## Location
Admin > Supplier Management > Settings > Risk questionnaire > Validation

## Purpose
Controls the validation applied when a risk questionnaire is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Requires L2 enablement |
| On | Legacy behaviour |
| Strict | Recommended for most tenants |
| Per business unit | Use for high-volume tenants |

## Impact of changes
Customers typically report this when a risk questionnaire is processed in bulk or immediately after an administrator changes Supplier Management settings. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-5370 and E-5379.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
