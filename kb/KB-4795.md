# E-3310: Bid submission is rejected

## Symptoms
Users see error **E-3310** when a bid submission is rejected. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a change to the buyer tenant's SAML/SSO configuration that was not followed by an update to the supplier portal trust relationship, so supplier session tokens are rejected at bid submit.

## Resolution
1. Confirm the buyer tenant SSO/SAML configuration changed recently (Admin > Security > SSO history).
2. Follow KB-7889 to re-establish the supplier portal trust relationship.
3. Ask the supplier to sign out, clear the session and resubmit the bid.
4. If the event closes within 48 hours, extend the event deadline to protect bid fairness.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a bid submission is processed in bulk or immediately after an administrator changes Sourcing settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
