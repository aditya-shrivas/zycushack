# How to: Configure 3-way match tolerances

## Before you start
Customers typically report this when a record is processed in bulk or immediately after an administrator changes eInvoice settings. Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.

## Steps
1. Sign in as a eInvoice administrator.
2. Go to eInvoice > Settings.
3. Select the option for: configure 3-way match tolerances.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
