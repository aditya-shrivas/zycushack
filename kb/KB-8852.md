# Configuration reference: Bank detail change numbering

## Location
Admin > Supplier Management > Settings > Bank detail change > Numbering

## Purpose
Controls the numbering applied when a bank detail change is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| Per business unit | Use for high-volume tenants |
| Global | Requires L2 enablement |
| 30 days | Recommended for most tenants |

## Impact of changes
Customers typically report this when a bank detail change is processed in bulk or immediately after an administrator changes Supplier Management settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-5367 and E-5370.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
