# Configuration reference: Data export default

## Location
Admin > Spend Analytics > Settings > Data export > Default

## Purpose
Controls the default applied when a data export is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 90 days | Use for high-volume tenants |
| Global | Recommended for most tenants |
| 60 minutes | Recommended for most tenants |
| Strict | Use for high-volume tenants |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a data export is processed in bulk or immediately after an administrator changes Spend Analytics settings. An incorrect value here is a common contributor to E-6167 and E-6213.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
