# Configuration reference: Supplier profile threshold

## Location
Admin > Supplier Management > Settings > Supplier profile > Threshold

## Purpose
Controls the threshold applied when a supplier profile is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Requires L2 enablement |
| On | Requires L2 enablement |
| Global | Legacy behaviour |
| Off | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-5327 and E-5367.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
