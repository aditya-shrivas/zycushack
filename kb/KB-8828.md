# Configuration reference: Punch-out session tolerance

## Location
Admin > eProcurement > Settings > Punch-out session > Tolerance

## Purpose
Controls the tolerance applied when a punch-out session is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 15 minutes | Recommended for most tenants |
| 30 days | Use for high-volume tenants |
| 60 minutes | Recommended for most tenants |
| 90 days | Requires L2 enablement |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a punch-out session is processed in bulk or immediately after an administrator changes eProcurement settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-1325 and E-1101.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
