# Configuration reference: Reverse auction default

## Location
Admin > Sourcing > Settings > Reverse auction > Default

## Purpose
Controls the default applied when a reverse auction is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| 90 days | Requires L2 enablement |
| 5 minutes | Requires L2 enablement |
| 30 days | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a reverse auction is processed in bulk or immediately after an administrator changes Sourcing settings. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. An incorrect value here is a common contributor to E-3139 and E-3115.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
