# Configuration reference: Compliance document currency

## Location
Admin > Supplier Management > Settings > Compliance document > Currency

## Purpose
Controls the currency applied when a compliance document is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Requires L2 enablement |
| On | Legacy behaviour |
| Lenient | Use for high-volume tenants |
| 90 days | Requires L2 enablement |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-5392 and E-5327.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
