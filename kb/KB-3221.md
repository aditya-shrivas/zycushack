# Configuration reference: Supplier invitation language

## Location
Admin > Sourcing > Settings > Supplier invitation > Language

## Purpose
Controls the language applied when a supplier invitation is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Recommended for most tenants |
| 90 days | Use for high-volume tenants |
| On | Use for high-volume tenants |
| Off | Legacy behaviour |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-3115 and E-3398.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
