# Configuration reference: 3-way match attachment limit

## Location
Admin > eInvoice > Settings > 3-way match > Attachment limit

## Purpose
Controls the attachment limit applied when a 3-way match is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| On | Requires L2 enablement |
| 15 minutes | Recommended for most tenants |
| Strict | Legacy behaviour |
| Off | Requires L2 enablement |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a 3-way match is processed in bulk or immediately after an administrator changes eInvoice settings. An incorrect value here is a common contributor to E-4211 and E-4157.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
