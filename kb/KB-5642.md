# E-7397: Master data import stays stuck in processing

## Symptoms
Users see error **E-7397** when a master data import stays stuck in processing. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a field value exceeding the allowed length.

## Resolution
1. Identify the field named in the error detail.
2. Shorten the value to the documented limit or request a limit increase.
3. Resubmit the record.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
