# How to: Run a reverse auction

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Sourcing settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.

## Steps
1. Sign in as a Sourcing administrator.
2. Go to Sourcing > Settings.
3. Select the option for: run a reverse auction.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
