# How to: Set up budget checks

## Before you start
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a eProcurement administrator.
2. Go to eProcurement > Settings.
3. Select the option for: set up budget checks.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
