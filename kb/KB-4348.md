# E-3387: Bid submission creates duplicate records

## Symptoms
Users see error **E-3387** when a bid submission creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by an exchange-rate table that was not refreshed.

## Resolution
1. Open Admin > Currency and check the last refresh date.
2. Run Refresh Rates now.
3. Re-run the affected calculation or report.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.
