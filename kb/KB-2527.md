# Configuration reference: Api token notification

## Location
Admin > Integrations > Settings > Api token > Notification

## Purpose
Controls the notification applied when a API token is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Requires L2 enablement |
| Lenient | Use for high-volume tenants |
| Per business unit | Recommended for most tenants |
| 5 minutes | Legacy behaviour |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-7342 and E-7141.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
