# FAQ: Can a contract template be restored after deletion?

## Answer
Retention follows the tenant's data retention policy, which is 7 years by default.

## Details
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a contract template is processed in bulk or immediately after an administrator changes Contracts settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Customers typically report this when a contract template is processed in bulk or immediately after an administrator changes Contracts settings.
