# Configuration reference: Certificate expiry alert default

## Location
Admin > Supplier Management > Settings > Certificate expiry alert > Default

## Purpose
Controls the default applied when a certificate expiry alert is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 30 days | Use for high-volume tenants |
| 90 days | Requires L2 enablement |
| Off | Recommended for most tenants |
| Global | Requires L2 enablement |

## Impact of changes
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a certificate expiry alert is processed in bulk or immediately after an administrator changes Supplier Management settings. An incorrect value here is a common contributor to E-5392 and E-5379.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
