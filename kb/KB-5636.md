# Configuration reference: Session validation

## Location
Admin > Platform > Settings > Session > Validation

## Purpose
Controls the validation applied when a session is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Legacy behaviour |
| Global | Requires L2 enablement |
| On | Requires L2 enablement |
| Off | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a session is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-8173 and E-8256.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
