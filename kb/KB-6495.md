# Configuration reference: E-signature request routing

## Location
Admin > Contracts > Settings > E-signature request > Routing

## Purpose
Controls the routing applied when a e-signature request is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Use for high-volume tenants |
| 5 minutes | Requires L2 enablement |
| 60 minutes | Legacy behaviour |
| Off | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-2126 and E-2185.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
