# E-2156: Obligation tracker is rejected

## Symptoms
Users see error **E-2156** when a obligation tracker is rejected. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a paused background scheduler job.

## Resolution
1. Open Admin > Scheduler and locate the paused job.
2. Resume the job and run it once manually.
3. Confirm downstream records update within 15 minutes.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a obligation tracker is processed in bulk or immediately after an administrator changes Contracts settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected.
