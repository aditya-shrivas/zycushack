# Configuration reference: User provisioning mapping

## Location
Admin > Platform > Settings > User provisioning > Mapping

## Purpose
Controls the mapping applied when a user provisioning is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Legacy behaviour |
| 15 minutes | Use for high-volume tenants |
| Per business unit | Recommended for most tenants |
| 60 minutes | Recommended for most tenants |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. Customers typically report this when a user provisioning is processed in bulk or immediately after an administrator changes Platform settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-8174 and E-8256.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
