# Configuration reference: Spend cube refresh threshold

## Location
Admin > Spend Analytics > Settings > Spend cube refresh > Threshold

## Purpose
Controls the threshold applied when a spend cube refresh is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Use for high-volume tenants |
| Per business unit | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |
| Global | Requires L2 enablement |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-6169 and E-6167.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
