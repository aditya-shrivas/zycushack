# How to: Create an RFx event

## Before you start
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating.

## Steps
1. Sign in as a Sourcing administrator.
2. Go to Sourcing > Settings.
3. Select the option for: create an rfx event.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
