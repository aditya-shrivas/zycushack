# FAQ: Who receives notifications for a currency conversion?

## Answer
No. This is a platform limit. Log a feature request if the business need is significant.

## Details
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Customers typically report this when a currency conversion is processed in bulk or immediately after an administrator changes Spend Analytics settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
