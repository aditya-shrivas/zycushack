# Configuration reference: Catalog item currency

## Location
Admin > eProcurement > Settings > Catalog item > Currency

## Purpose
Controls the currency applied when a catalog item is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Recommended for most tenants |
| 60 minutes | Requires L2 enablement |
| 90 days | Recommended for most tenants |
| Per business unit | Legacy behaviour |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-1325 and E-1287.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
