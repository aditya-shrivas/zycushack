# Configuration reference: 3-way match frequency

## Location
Admin > eInvoice > Settings > 3-way match > Frequency

## Purpose
Controls the frequency applied when a 3-way match is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Recommended for most tenants |
| 60 minutes | Use for high-volume tenants |
| On | Use for high-volume tenants |
| 90 days | Use for high-volume tenants |

## Impact of changes
This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-4329 and E-4256.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
