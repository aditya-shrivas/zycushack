# E-7172: Sftp file transfer shows incorrect values

## Symptoms
Users see error **E-7172** when a SFTP file transfer shows incorrect values. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by a paused background scheduler job.

## Resolution
1. Open Admin > Scheduler and locate the paused job.
2. Resume the job and run it once manually.
3. Confirm downstream records update within 15 minutes.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
Customers typically report this when a SFTP file transfer is processed in bulk or immediately after an administrator changes Integrations settings. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
