# Configuration reference: Saml assertion attachment limit

## Location
Admin > Platform > Settings > Saml assertion > Attachment limit

## Purpose
Controls the attachment limit applied when a SAML assertion is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Requires L2 enablement |
| 90 days | Requires L2 enablement |
| 15 minutes | Legacy behaviour |
| 5 minutes | Legacy behaviour |

## Impact of changes
Customers typically report this when a SAML assertion is processed in bulk or immediately after an administrator changes Platform settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. Most cases are resolved by a tenant administrator without engineering involvement. An incorrect value here is a common contributor to E-8205 and E-8143.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
