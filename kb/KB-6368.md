# Configuration reference: Clause library notification

## Location
Admin > Contracts > Settings > Clause library > Notification

## Purpose
Controls the notification applied when a clause library is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 60 minutes | Legacy behaviour |
| Off | Recommended for most tenants |
| 15 minutes | Use for high-volume tenants |
| Lenient | Requires L2 enablement |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-2138 and E-2109.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
