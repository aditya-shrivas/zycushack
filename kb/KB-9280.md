# How to: Rotate API tokens

## Before you start
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a record is processed in bulk or immediately after an administrator changes Integrations settings.

## Steps
1. Sign in as a Integrations administrator.
2. Go to Integrations > Settings.
3. Select the option for: rotate api tokens.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
