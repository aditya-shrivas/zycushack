# Configuration reference: Classification job currency

## Location
Admin > Spend Analytics > Settings > Classification job > Currency

## Purpose
Controls the currency applied when a classification job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Global | Requires L2 enablement |
| On | Requires L2 enablement |
| Lenient | Use for high-volume tenants |
| Per business unit | Requires L2 enablement |

## Impact of changes
Most cases are resolved by a tenant administrator without engineering involvement. The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-6159 and E-6295.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
