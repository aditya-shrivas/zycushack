# Configuration reference: Erp sync job language

## Location
Admin > Integrations > Settings > Erp sync job > Language

## Purpose
Controls the language applied when a ERP sync job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| 5 minutes | Legacy behaviour |
| 60 minutes | Use for high-volume tenants |
| Per business unit | Legacy behaviour |
| 15 minutes | Recommended for most tenants |

## Impact of changes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Most cases are resolved by a tenant administrator without engineering involvement. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. An incorrect value here is a common contributor to E-7249 and E-7308.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
