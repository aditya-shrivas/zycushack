# Configuration reference: Payment file timeout

## Location
Admin > eInvoice > Settings > Payment file > Timeout

## Purpose
Controls the timeout applied when a payment file is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Strict | Recommended for most tenants |
| Per business unit | Legacy behaviour |
| Global | Requires L2 enablement |
| Off | Legacy behaviour |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a payment file is processed in bulk or immediately after an administrator changes eInvoice settings. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path. An incorrect value here is a common contributor to E-4320 and E-4144.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
