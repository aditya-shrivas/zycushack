# E-8174: Sso login creates duplicate records

## Symptoms
Users see error **E-8174** when a SSO login creates duplicate records. The record remains in its previous state and no notification is sent.

## Cause
This error is caused by an expired integration credential.

## Resolution
1. Open Admin > Integrations > Credentials.
2. Regenerate the credential and update it in the connected system.
3. Trigger a manual sync and confirm the job status shows Completed.

## Escalation criteria
Escalate to L2 Engineering if the resolution steps fail, if more than 50 records are affected, or if the customer reports the issue on multiple tenants.

## Notes
The issue affects only the tenant where the configuration was changed. Other tenants on the same release are not affected. Customers typically report this when a SSO login is processed in bulk or immediately after an administrator changes Platform settings. If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually.
