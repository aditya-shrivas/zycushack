# Configuration reference: Classification job visibility

## Location
Admin > Spend Analytics > Settings > Classification job > Visibility

## Purpose
Controls the visibility applied when a classification job is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Per business unit | Use for high-volume tenants |
| Off | Requires L2 enablement |
| On | Recommended for most tenants |
| Strict | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a classification job is processed in bulk or immediately after an administrator changes Spend Analytics settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-6213 and E-6169.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
