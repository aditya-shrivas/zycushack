# How to: Create a contract from a template

## Before you start
Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. Most cases are resolved by a tenant administrator without engineering involvement. This article applies to tenants on release 26.1 and later. Earlier releases display the same behaviour but use a different admin menu path.

## Steps
1. Sign in as a Contracts administrator.
2. Go to Contracts > Settings.
3. Select the option for: create a contract from a template.
4. Enter the required values and save.
5. Verify the change on a test record before announcing it to users.
