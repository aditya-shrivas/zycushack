# Configuration reference: Bid submission retention

## Location
Admin > Sourcing > Settings > Bid submission > Retention

## Purpose
Controls the retention applied when a bid submission is created, updated or processed. Changes apply to new records only unless the administrator selects Reapply to open records.

## Allowed values
| Value | Guidance |
|---|---|
| Off | Legacy behaviour |
| 90 days | Use for high-volume tenants |
| 30 days | Legacy behaviour |
| 60 minutes | Recommended for most tenants |

## Impact of changes
If more than one tenant reports the same error within 24 hours, treat it as a potential platform incident and check the Known Issues list before troubleshooting individually. Customers typically report this when a bid submission is processed in bulk or immediately after an administrator changes Sourcing settings. Collect the tenant ID, the affected record ID, the exact error text and the time of failure in UTC before escalating. An incorrect value here is a common contributor to E-3115 and E-3398.

## Audit
Every change to this setting is recorded in the admin audit log with the acting administrator's role and a timestamp.
